# 🆕 Новые функции калькулятора UniCheck

## 🌐 Многоязычность

Калькулятор теперь поддерживает два языка:
- 🇷🇺 **Русский** (по умолчанию)
- 🇺🇸 **Английский**

### Как переключить язык:
1. В левой панели (sidebar) найдите секцию "Язык / Language"
2. Выберите нужный язык из выпадающего списка
3. Интерфейс автоматически обновится на выбранном языке

## 🎛️ Слайдеры для параметров

Добавлен новый режим ввода параметров с помощью слайдеров для более удобного взаимодействия.

### Как переключить режим ввода:
1. В левой панели найдите секцию "Режим слайдеров" / "Slider Mode"
2. Выберите между двумя режимами:
   - **Поля ввода** / **Number Inputs** - классический режим с полями для ввода чисел
   - **Слайдеры** / **Sliders** - интерактивные ползунки для изменения значений

### Преимущества слайдеров:
- 🎯 Быстрое изменение параметров
- 📊 Визуальное представление диапазонов значений
- 🔄 Мгновенное обновление результатов при перемещении
- 🎮 Более интуитивный интерфейс

## 🔧 Технические детали

### Переводы
- Все тексты интерфейса вынесены в отдельный файл `translations.py`
- Легко добавить новые языки, расширив словарь `TRANSLATIONS`
- Переводы покрывают все элементы: заголовки, поля, кнопки, таблицы, графики

### Слайдеры
- Автоматическое определение подходящих диапазонов для каждого параметра
- Поддержка как целых чисел, так и дробных значений
- Сохранение текущих значений при переключении режимов

### Совместимость
- Все существующие функции работают без изменений
- Сохраненные пресеты совместимы с новой версией
- URL-параметры по-прежнему поддерживаются

## 🚀 Запуск

Запуск приложения остается прежним:

```bash
# Из папки проекта
streamlit run app.py

# Или используя виртуальное окружение
.venv/bin/python -m streamlit run app.py
```

## 🎨 Дизайн

- Переключатель языка размещен в самом верху левой панели
- Переключатель режима ввода расположен сразу после языка
- Все элементы имеют интуитивные иконки (🇷🇺🇺🇸 для языков, 🎛️ для режимов)
- Дизайн остается консистентным во всех языках
